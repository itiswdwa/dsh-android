# dsh-android 1.1.3

把 DeepSeek Harness 装进安卓手机：一个 APK，自带 Ubuntu 运行时，不需要 Termux、不需要 root。

## 这一版修了什么

- **修好了「应用打不开」**：从更早版本升上来的用户，升级后可能出现界面停在启动画面、
  服务起不来的情况。原因是升级时要清理旧的 Alpine 运行环境，而那次清理是在主线程上做的，
  旧树里又有一万多个无法删除的残留文件 —— 于是每次启动都卡在那里。现在清理放到后台、
  只做一次，删不掉就改名挪开，不再阻塞启动。
- **修好了「挂载不生效」**：以前挂载的源目录如果应用读不到（比如 `Android/data`、
  SD 卡、或没授予存储权限），会被**静默丢弃**，沙箱里只看到一个空目录。
  现在设置页会直接写出原因，并且每条挂载都有 **「测一下」** 按钮 ——
  它让沙箱真的去列一次目录，绑上没有、里面有什么，一眼就有答案。
- 挂载的管理界面补上了 **「重启服务以生效」** 按钮（挂载是启动参数，做不到热插拔）。

## 安装

1. 下载下面的 `dsh-android.apk`（143 MB），拷到手机点安装。
2. 覆盖安装即可，**会话、API Key、挂载、设置都会保留**。
3. 首次启动需要解包内置运行时，约 2 分钟（只有这一次），之后冷启动约 5 秒。

## 更新方式

应用里 设置 → 安卓沙箱 → **检查更新**：

- **热更新**（几十 KB）：插件、技能、系统提示词、沙箱脚本 —— 一键应用，不用重装；
- **重要更新**（143 MB，就是本页的 APK）：外壳、界面、图标这种改动。

拿到 `dsh-hot.zip` 也可以离线导入：放进手机的 `Download` 目录，重开应用即可。

## 已知限制

- 只支持 arm64 的 Android 8.0+ 设备。
- 应用操作手机本身（截图、开关应用、改设置）需要用户自行安装并授权
  [Shizuku](https://shizuku.rikka.app/)。
- 手机开着 fake-IP 模式的代理时，harness 的 `web_fetch` 会按设计拒绝所有公网域名，
  让助手改用 `bash` + `node fetch` 即可。
