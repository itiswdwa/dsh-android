# 热更新包 1.1.4-sp2

**不用重装 APK**：应用还是 1.1.4，这一包只换插件（界面）。

装上这一包，`1.1.4-sp1` 的内容一并到手（sp2 是它的后继），另外多了两处：

- **热包版本号改成看得懂的写法**：`<应用版本>-sp<序号>`，也就是 `1.1.4-sp1`、`1.1.4-sp2`……
  没有热更新时就是应用版本本身（`1.1.4`）。以前那串 16 位内容哈希不再拿来显示，
  但仍然打在包里的 `hot.json.hash` 上，用来判断"两台设备的插件是不是同一份"。
- **设置页顶部不再截断版本号**：以前显示到第 8 个字符（`1.1.4-sp`），现在整串显示。

## 这一包改了什么

**「安卓沙箱」设置页重画了一遍，和 harness 原生的设置页长成同一个样子。**

以前这一页是插件自己画的一套：灰底圆角卡片、蓝色按钮、自定字号，和旁边的「通用设置」「模型」
摆在一起像是两个应用拼起来的。现在它用的是 harness 自己的那套东西：

- **控件全部来自原生组件库**（`@deepseek-ai/dsh-client-ui-primitives`）——按钮、开关、状态点、
  标签都是 harness 自己那几个，所以 hover、按下、焦点环、禁用态、无障碍角色跟原生完全一致，
  不再是"看起来有点像"。
- **颜色只走主题令牌**（`--dsw-*`），一个写死的颜色都没有，所以深色模式（以及以后换主题）都不用改这里。
- **排版用原生设置页的形状**：18px/600 标题 + 13px 灰色说明，字段之间是 0.5px 发丝线，
  分组用 `settings-card` 那层描边卡片 —— 和「通用设置」里"权限 / 语言 / 字号大小"那几行是一个模子。
- 顺带把几处一直写死中文的地方（挂载的「启用 / 停用」、日志的「（无输出）」、发行版的「内置」）
  收进了语言表。

功能一个没少：服务启停、发行版切换与启动命令、热更新检查与应用、导出到手机、挂载（含"为什么这个
挂载看不到东西"的提示）、Shizuku 状态与测试命令、端口 / Key / 三个开关、日志。

## 怎么用

应用内：**设置 → 安卓沙箱 → 检查更新 → 应用热更新**，然后重开应用。

离线：把 `dsh-hot.zip` 放进手机 `Download` 目录，重开应用会自动导入。

装完这一包，设置页顶部应该显示 `应用 1.1.4 · 热包 1.1.4-sp2 · 已导入`。
